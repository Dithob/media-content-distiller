# 输出规则

## 主稿与副产物

主稿只写用户真正需要阅读的内容。完整时间轴、逐条证据、覆盖判断、背景补充和无法
确认项放到来源 ID 目录：

```text
media-artifacts/
├── <主稿文件>.md
└── <source-id>/
    ├── README.md
    ├── raw-subtitle.json
    ├── metadata.json
    ├── transcript.md
    ├── timeline.md
    ├── evidence.md
    └── boundaries.md
```

主稿末尾只保留简短的副产物导航，不要把副产物全文复制进主稿。

## 文件名

- 总结笔记：`<媒体标题>摘要.md`
- 详细总结：`<媒体标题>详细总结.md`
- 结构梳理：`<媒体标题>结构梳理.md`
- 操作手册：`<软件或主题>操作手册.md`
- 学习文档：`<媒体标题>学习笔记.md`
- 时间轴转录：`<媒体标题>时间轴转录.md`

标题过于泛化时，根据字幕提炼主题；操作手册优先使用软件、产品或主题名称。

## 证据标签

- **字幕已验证**：字幕或媒体元数据直接支持；
- **背景补充**：来自模型知识、本地资料或联网搜索；
- **当前任务判断**：Codex 根据用户目标做出的归纳；
- **无法确认**：字幕缺失、含混或证据不足。

结构章节应标记为“基于字幕推断”，不能称为官方章节。用户要求当前版本、价格、法规
或外部核验时，才搜索网络，并把结果标成背景。
