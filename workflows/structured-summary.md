# 结构化 / 章节总结

## Triggers

“分章节总结”“按主题拆分”“视频结构”“列出每段讲什么”。

## Steps

1. 先获取字幕和时间轴；不调用 BibiGPT 官方章节总结接口。
2. 根据主题切换、论点转折、案例边界和时间间隔归纳章节。
3. 每个章节写标题、时间范围、核心内容和需要回查的 cue。
4. 如果字幕无法支持清晰章节边界，明确写“基于字幕推断的结构”，不要称为官方章节。

## Output

| 时间 | 基于字幕归纳的章节 | 核心内容 | 证据 |
|---|---|---|---|
| 00:00–05:00 | ... | ... | 字幕已验证 |

章节结构是 Codex 的分析结果，不是 BibiGPT API 返回的字段。
