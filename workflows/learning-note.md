# 学习文档

## Triggers

“整理成学习文档”“判断值不值得学”“给我前置知识和实操价值”“归纳到知识库”。

## Steps

1. 先完成字幕获取、标准化和转录；再根据用户目标组织学习材料。
2. 按主题完整保留解释、案例、风险、限制、因果关系和结论。
3. 结合用户习惯、本地知识库和模型知识补充必要背景；需要当前信息时联网核验并标注来源。
4. 明确区分字幕事实、背景补充和当前任务判断。
5. 给出前置知识、实操价值、内容密度、重复/拖沓处、适合人群和推荐跳读时间段。
6. 需要归档时再交给 `daily-note-kb-distiller`，不要把字幕底稿和知识判断混为一体。

## Output

```markdown
# 标题｜学习文档
## 一句话结论
## 视频内容完整梳理
## 结构与关键知识点
## 前置知识
## 实操价值
## 内容密度与跳读建议
## 证据说明
## 时间轴回查
```
